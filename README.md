# 売上管理ツール(オフライン対応PWA)

Progressive Web App (PWA) として動作する、オフライン環境でも使える売上管理ツールです。
ビルド不要の素の HTML / CSS / JavaScript で構築されており、データは各端末内の IndexedDB にのみ保存されます(外部サーバーへの送信はありません)。

**商品マスタ管理 / 売上入力 / 集計レポート / 顧客管理** の4画面を実装しています。

公開URL: https://tukuyomi1189.github.io/sales-management-pwa/

## 主な機能

### 売上入力
- 登録済みの商品をタイル形式のグリッドから**タップするだけで明細に追加**(レジ風のかんたん入力)。同じ商品を続けてタップすると数量が+1される
- 明細の数量は **＋/－ボタン**で増減(数字部分は直接タップして編集も可能)。単価も明細ごとに編集可能
- 売上日時は**「登録する」を押した瞬間の日時を自動記録**(手動入力欄はなし)。編集時も元の売上日時は変わらない
- 顧客(任意)・メモを指定可能
- 売上を登録すると、明細分の商品在庫が自動的に減算される(削除・編集時は自動的に復元)
- 在庫を超える数量を指定した場合は警告を表示(登録自体はブロックしない)
- 顧客名・商品名・メモでの検索
- 売上一覧はチェックボックスで複数選択し、まとめて削除可能(全選択チェックボックスあり)。個別削除・一括削除のどちらも削除前に確認ダイアログを表示し、削除すると明細分の在庫が元に戻る
- JSONエクスポート / インポート(端末間でのデータ移行用。インポートしても在庫数は変更されない)

### レポート(集計)
- 期間プリセット(今月 / 先月 / 直近7日 / 直近30日 / 全期間 / カスタム)による絞り込み
- 期間合計売上・件数・平均客単価のサマリー表示
- 売上推移グラフは「日別」(期間が長い場合は自動的に月別集計に切り替え)と「時間帯別」(指定した1日の0〜23時の売上)を切り替え可能
- 商品別・顧客別の売上ランキング

### 商品マスタ管理
- 商品の登録・編集・削除(商品コード / 商品名 / カテゴリ / 単価 / 在庫数 / 単位 / メモ)
- 商品名・商品コード・カテゴリでのキーワード検索
- 在庫少バッジ表示、登録件数・在庫合計・在庫評価額のサマリー表示
- JSONエクスポート / インポート(バックアップ・復元用)

### 顧客管理
- 顧客の登録・編集・削除(顧客名 / 担当者名 / 電話番号 / メール / 住所 / メモ)
- 顧客名・担当者名での検索
- JSONエクスポート / インポート(端末間でのデータ移行用)

### 共通
- オンライン / オフライン状態の表示
- ホーム画面へのインストール(Add to Home Screen)対応

## 技術スタック

- 素の HTML / CSS / JavaScript(ビルドツール・フレームワーク不使用)
- データ保存: IndexedDB([js/db.js](js/db.js))— 商品・顧客・売上の3ストア
- オフラインキャッシュ: Service Worker([service-worker.js](service-worker.js))によるアプリシェルのキャッシュ
- 画面切り替え: ハッシュベースの簡易ルーター([js/router.js](js/router.js))
- グラフ: 外部ライブラリを使わず SVG を直接描画(CDN依存をなくしオフラインでも確実に表示するため)
- PWAマニフェスト: [manifest.json](manifest.json)


## データモデルのポイント

- 売上(`sales`)の明細には、登録時点の商品名・単価をスナップショットとして保存しています。そのため商品マスタを後から編集・削除しても、過去の売上記録の表示内容は変わりません。
- 売上の登録・編集・削除は、対応する商品の在庫数と同一トランザクション内で更新されます(IndexedDBの複数ストアにまたがるトランザクション)。
- 売上の日時は「登録する」ボタンを押した瞬間の日時([js/db.js](js/db.js) の `SalesDB.add`)で自動的に決まり、以後の編集では変更されません(`SalesDB.update` は `date`/`createdAt` を上書きしない設計)。

## オフライン環境での使用方法

このアプリは **一度読み込むとオフラインでも完全に動作します**。仕組みは次の2段構えです。

1. **Service Worker がアプリ本体(HTML/CSS/JS/アイコン)をキャッシュ**するため、ネットワークがなくても画面が表示されます。
2. **すべてのデータ(商品・顧客・売上)は IndexedDB に保存**されるため、ネットワークがなくても登録・編集・削除・検索・集計がすべて行えます。

### 注意点

- Service Worker は **HTTPS または localhost でしか動作しません**。`file://` で直接 `index.html` を開いたり、`http://` の LAN IP(例: `http://192.168.x.x:8080`)でアクセスした場合はオフラインキャッシュが有効になりません。
- データは **端末・ブラウザごとに独立**しています(PCとスマホ、Chrome と Safari 等で共有されません)。端末間でデータを移したい場合は下記の「端末間でデータを共有する」を参照してください。
- コード更新後にオフラインキャッシュを確実に更新させたい場合は、[service-worker.js](service-worker.js) 冒頭の `CACHE_VERSION` を上げてから再デプロイしてください。
- 既存のブラウザ環境に商品マスタ(v1)のデータがある場合でも、IndexedDBのバージョンアップ処理により **既存の商品データを保持したまま** 顧客・売上ストアが追加されます。

## ローカルで動かす

```bash
cd sales_management_project
python -m http.server 8080
```

ブラウザで `http://localhost:8080` を開きます(`localhost` は secure context 扱いのため Service Worker が有効になります)。一度読み込めば、以降はネットワークを切っても利用できます。

## 端末間でデータを共有する

自動的なクラウド同期はありません(オフライン専用のため)。端末間でデータを移したい場合は、各画面の **JSONエクスポート / インポート** を使って手動でファイルを受け渡します。

1. 移行元の端末で、商品マスタ・顧客管理・売上入力のそれぞれの画面から「JSONエクスポート」でファイルをダウンロードする
2. ダウンロードした3つのJSONファイルを、メールやクラウドストレージ等で移行先の端末に送る
3. 移行先の端末で、同じ画面の「JSONインポート」からファイルを選択する(**商品 → 顧客 → 売上の順**にインポートすることを推奨。売上明細は商品名などをスナップショットとして保持しているため、順序を守らなくても表示は壊れませんが、この順だと在庫の数字が最も分かりやすくなります)

### 注意点
- インポートは既存データに**追加**されます(置き換えではありません)。同じファイルを2回インポートすると重複します。
- 売上をインポートしても、**商品の在庫数は変更されません**。売上ごとに在庫を再計算して二重に減算してしまうのを避けるためです。エクスポート時点の在庫数を反映したい場合は、商品マスタのJSONも一緒にインポートしてください。
- 売上データは元の売上日時(登録した瞬間の日時)を保持したままインポートされます。
- 複数人が同時に同じデータを編集する用途(リアルタイム共有)には対応していません。同時編集が必要な場合はクラウドサービス(Firebaseなど)によるリアルタイム同期の導入が別途必要です。

## スマホで使う

1. 公開URL(https://tukuyomi1189.github.io/sales-management-pwa/ )をスマホのブラウザで開く
2. ホーム画面に追加してインストール
   - **Android (Chrome)**: 右上メニュー(⋮) → 「アプリをインストール」または「ホーム画面に追加」
   - **iPhone (Safari)**: 共有ボタン → 「ホーム画面に追加」
3. インストール後はホーム画面のアイコンから単体アプリとして起動でき、機内モードでも利用できます
